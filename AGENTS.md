# Project instructions

## Scope

- Never go far beyond the scope of the user's request.

## Neutral names in repository files

- Use only neutral names when creating or editing files visible to Git, including tracked files and non-ignored untracked files.
- Do not introduce names of external game projects, games, enemies, characters, or other identifiers specific to those projects. This applies to file names, code, tests, fixtures, string literals, comments, documentation, and diagnostic messages.
- Use generic names such as `Test Frame`, `Test Value`, `Test Group`, and `Test Sprite`. Describe regression cases by the behavior they verify, without identifying the external source project or its characters.
- `Mario Forever`, with exactly this spelling, is explicitly allowed as a neutral name.
- Before finishing changes, check the changed files for external project names and replace them with neutral names.

## Sub-agents

- Never use the Astra model for sub-agents.
- Use medium reasoning effort for reviewing or inspection.
